## Standing rule

This table is a **beginning-of-book** snapshot. Every future gate/
chapter that changes a character's knowledge state must update the
relevant cell here (or, once it exists, in
`05_mystery/mara_knowledge_timeline.md`) — an outdated knowledge matrix
is worse than none, because it will be trusted.
