# Chapter Briefs

STATUS: EMPTY — pending Gate 5 closure.

## What belongs here

One file per chapter (suggested convention: `chapter-01-brief.md`
through `chapter-46-brief.md`, grouped by part if that proves easier to
navigate), each specifying POV, scene list, goal, clues planted/
reinforced/withheld (cross-referenced to `05_mystery/clue_register.md`),
entry/exit state, this chapter's specific prohibited revelations
(cross-referenced to `05_mystery/reveal_ladder.md`), and target word
count — per `00_project/production_workflow.md`'s drafting workflow.

## Why this directory is empty

Per `CLAUDE.md`'s hard rule: no chapter brief is written before Gates
0–5 are complete. This repository has closed Gates 0–1 only. Do not
write a chapter brief here to "get ahead" — an early brief written
against an unfinished mystery architecture and structure will need to be
rewritten once Gates 2–5 actually close, which wastes the effort and
risks the brief quietly becoming de facto canon before it's been
validated.

## Prerequisite

`00_project/quality_gates.md` Gates 2–5 all closed, specifically
`04_plot/chapter_map.md` and `05_mystery/reveal_ladder.md`.
