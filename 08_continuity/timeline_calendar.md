# Timeline Calendar

STATUS: READY, EMPTY — living register, to be populated once drafting
begins. Distinct from `ages_and_dates.md` (which holds the backstory's
relative-year anchor points): this file tracks the **story-present**
calendar day by day as chapters are drafted — what day of the week and
relative date each chapter's action occurs on, and the running weather/
season if it becomes plot-relevant — so a 46-chapter, multi-session draft
doesn't quietly lose track of how much story-time has passed.

## Conventions to use once populated

- Story time is not yet pinned to a real calendar year (avoid dating the
  book to real datable events, consistent with
  `02_novel_bible/setting_bible.md`'s "present-day, contemporary,
  unpinned" rule) — track relative story-days and days-of-week only.
- Season: not yet decided. Working note for Gate 4: the investigation's
  pacing (weeks to a few months, per `08_continuity/ages_and_dates.md`'s
  open item) should pick a season deliberately if weather/light becomes a
  scene-setting tool, the way it did in this project's sibling drafting
  session — not left arbitrary.
- Table format recommended once chapters exist: `Story day | Day of
  week | Chapter(s) | Key events`, matching the convention already
  proven useful in this project's methodology.

## Prerequisite

At least one drafted chapter.
