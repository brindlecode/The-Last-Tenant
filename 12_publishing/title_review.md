STATUS: RESOLVED this session (Gate 2/3 pass). This is now the
authoritative title record — supersedes the Gate 1 "keep as working
title, flag the risk" holding position. See `DECISION_LOG.md` for the
dated decision entry; see `00_project/gate_1_concept_validation.md`
(left untouched, per that file's own no-silent-edit rule) for the
original Gate 1-level flag this session resolved.

## Why this needed a real decision, not another deferral

`00_project/risk_register.md` R-013 and Gate 1's own title stress-test
flagged "THE LAST TENANT" as a real, not hypothetical, collision: this
repository's own rejected branch (`claude/last-tenant-part-one-ch1-4-nfwdvx`)
used the identical title for a different, non-canon novel, and a related
project by this same author used the near-identical "THE SILENT TENANT."
Keeping a title that's already known to collide with material this
project has explicitly and permanently rejected is a live confusion risk
for any future session, reviewer, or reader-facing use — not just a
distant marketing concern. With zero manuscript prose drafted, the cost
of changing it now is at its lowest possible point in the project's
life. Deferring a third time was judged worse than deciding.

## Method

Twenty candidate titles were generated before any were scored, covering
distinct source strategies (a Mara/Elena-family theme; the Apartment 4C
mechanism; Palinode's own vocabulary; the seven-witnesses structure; the
insurance-procedural angle) so the comparison wouldn't just be twenty
variations on one idea. Each was scored against five criteria:
**uniqueness** (checked via web search where a real collision was
plausible, not assumed), **thematic resonance** (does it work on more
than one level — plot mechanism *and* the sisters' emotional argument),
**genre cadence** (does it read correctly on a thriller/domestic-suspense
shelf), **memorability**, and — weighted deliberately heaviest, per
`risk_register.md` R-010's standing priority that the emotional core must
never lose to plot machinery, including at the level of title selection
— whether it centers the human theme or the mystery mechanism.

## Selected: A BORROWED NAME

**Reasoning.** It is the only title in the set that is simultaneously
(a) clear of any real collision found this session, (b) resonant on
every level the book actually operates on — Mara's Palinode-assigned
surname, Elena's seven performed identities, the family's manufactured
origin, *and* the sisters' relationship itself (a name, like trust, can
be lent, held carefully, or broken by misuse) — and (c) written in a
commercially proven register for the genre without borrowing any specific
existing title's shape. Most importantly under R-010's standing
priority: it names the human theme (identity as something held in trust
between people) rather than the mystery's mechanism (a vacancy, a clause,
a policy) — the same priority that decided the opening-option selection
(`04_plot/opening_options.md`) and the ending-architecture refinement
(`04_plot/ending_options.md`) is applied here too, for consistency.

**Runners-up preserved, not discarded**: THE VACANCY CLAUSE and PROOF OF
CLAIM remain strong if a later gate finds the manuscript's finished tone
leans more procedural than this bible currently intends; SEVEN NAMES FOR
ELENA and EVERY NAME BUT HERS remain strong if a later gate wants a more
overt, high-concept marketing hook. THE ASSIGNED NAME and A PATTERN OF
LOSS remain close alternates in the same register as the winner.

## Standing rule going forward

Per `00_project/originality_policy.md` and this session's own experience
with R-013: a title decided this early should still get one further,
real marketplace search (Amazon/major retailer listings, Goodreads,
recent industry announcements, specifically for "A Borrowed Name" in the
adult fiction category) at the pre-submission stage, per
`12_publishing/submission_checklist.md` — this session's web searches
were a genuine but not exhaustive clearance check, not a substitute for
that later pass.
